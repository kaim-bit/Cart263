The work that i observed was the game word nerd by jakes group. I was blown out the water right out of the gate, this game was much more developed and clean then i originally thought this assignments "bar" would entail. at the start you are met with a sleek, clean and simple title screen that says "word nerd". The theme of this title page is pixelated/arcade, and contains a simple color group of intresting colors, purplle, gold, pink and white. The game on starting prompts the player to type a word that contains a letter group that is randomly generated. this letter group changes after the player correctly enters a word containing the letter group. this continues until the timer ends, resulting in a "rush" type of game mechanic to where the player feels a stress to get as many words as possible. The special effects are also amazing in this game. when the player correctly enters a word, a tiny little token flings out in a random direction and falls down through the website border. The starting screen also has a sliding difficulty bar that is very clean aswell. You can also change the dictionary in which you have to find words that both fit thee letter group aswell as the topic of the dictionary. A great addition aswell is the settings tab with a nice animated cog when clicked, and again very clean design for the settings menu itself with yet another sliding bar for the volume. The coding itself is tidy and smart aswell, organized between 2 js files, one for mechanics the other for looks. The code has great note taking aswell as organization for game starting and ending functions, making transitions between states much more tolerable to understand and work with. all of the code critically uses query select, looking for the randomly generated letter combo and comparing it to a dictionary and finding all words that can connect. I think what is most shocking to me about this program is the effort of how much data was added to make this game work, huge amounts of words! I really love this project overall and it sadly puts me to shame. I talked to my teamates and we felt as if maybe we should have applied ourselfs to this project like this team does. This final i hope that the quality of our own project is simular to the work that they produce in the coming weeks.
